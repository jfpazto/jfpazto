## Proyecto destacado

### [Ciudad de agentes](https://github.com/jfpazto/agent-city)

Una ciudad 2.5D para ver en el navegador las sesiones de Claude Code y Codex. Cada edificio representa un proyecto y cada piso, una sesión: puedes ver cuáles están trabajando y cuáles necesitan tu atención.

[![Ciudad de agentes: vista de demostración con proyectos y sesiones de ejemplo](https://raw.githubusercontent.com/jfpazto/agent-city/main/docs/capturas/mapa-demo-20261026.png)](https://github.com/jfpazto/agent-city)

Permite consultar tokens, coste estimado y uso de contexto, además de rebobinar la actividad de los últimos días. Funciona en local. La captura muestra datos de demostración.

[Ver código e instalación](https://github.com/jfpazto/agent-city#instalación) · [Arquitectura](https://github.com/jfpazto/agent-city/blob/main/ARCHITECTURE.md)
